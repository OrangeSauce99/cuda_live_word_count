# Live Word Count

**Live Word Count**, also known as **Cuda Live Word Count** is a simple python plugin for the text editor [Cudatext](https://cudatext.github.io/). This plugin shows a live word and character counter of the current open tab. The counter is displayed in the Bottom-Right Corner.

## How To Install?
1. Open Cudatext, on the top bar, click "Plugins", then "Addons Manager" and then "Install..."
2. Search "Live Word Count", and finally install.

**Another installation method:**
1. Find where you've installed Cudatext (C:\Program Files\Cudatext by default on Windows), go into \Cudatext\py\ now create a folder named "cuda_live_word_count" inside the py folder.
2. Download the 2 files "__init__.py" and "install.inf" from this Github repository.
3. Now, copy those 2 files and paste them inside of "cuda_live_word_count" folder, which is inside \Cudatext\py\.
